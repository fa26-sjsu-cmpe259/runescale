# Peer testing

The course requires at least two classmates to test the assistant. This file holds the protocol to hand them and the summary that goes in the final artifacts. Fill in the summary from real sessions only.

## Protocol (about 20 minutes per tester)

1. Run the app locally (`npm run dev`) or share your screen. Start on config **B1** (Claude, tool-grounded).
2. Give the tester this brief and nothing else: *"You're a Dungeon Master prepping a fight. Use Runescale to check whether it's balanced, then try to break it."*
3. Let them drive. Note what they type, where they hesitate, and anything they misread. Don't explain the UI unless they're stuck for more than a minute.
4. Halfway through, turn on **Compare side by side** with B1 vs A1. Ask them to run one encounter through both.
5. Prompts to suggest if they run out of ideas:
   - Build an encounter on the board and ask "Is this fair?"
   - Ask "Make this harder" and click one of the **Apply** buttons.
   - Ask about a monster that isn't in the SRD, such as one from a published adventure.
   - Ask something vague, or something off-topic.
6. Close with these questions:
   - Did you trust the rating? Why or why not?
   - Was anything confusing about the meter or the tool cards?
   - What would you want it to do that it didn't?
